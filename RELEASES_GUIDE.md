# NBoard - Installer & Distribution

## 📥 Download & Install

### Option 1: Download Pre-Built Installer (EASIEST) ⭐

**What you get:**
- ✅ NBoard-Setup.msi (Professional installer)
- ✅ Automatic desktop shortcut
- ✅ Auto-launch on first run
- ✅ Ready to use - no configuration needed

**How to install:**
1. Download `NBoard-Setup.msi` from Releases

1. Download `NBoard-Portable.zip`

## ✅ System Requirements

**Before you download, ensure you have:**

1. **Windows 10 or Windows 11** (64-bit)
2. **.NET 6.0 Desktop Runtime** installed

### Check if you have .NET 6.0

Open **Command Prompt** and run:
```bash
dotnet --version
```

If you see `6.0.x` or higher - you're ready! ✅

If not, download it first:
- **Link:** https://dotnet.microsoft.com/download/dotnet/6.0
- **Choose:** "Desktop Runtime" (NOT SDK)
- **Install:** Follow wizard, restart PC

- **Location:** Windows Start Menu → NBoard

## 🎯 First Time Use

1. **Launch NBoard**
   - Double-click desktop shortcut OR
   - Search Start Menu for "NBoard"

2. **Welcome Screen Appears**
   ```
   [ NBoard - Professional Whiteboard ]
   
   [+ Create New Document]
   
   [📁 Open File]  [⚙️ Settings]
   ```

   - New blank canvas opens
   - Toolbar with drawing tools appears

## ❓ Common Questions

### Q: Do I need Visual Studio?
**A:** NO! Visual Studio is NOT needed. Just install .NET 6.0 Runtime and run NBoard.exe

### Q: Do I need to do anything after installation?
**A:** NO! Just double-click the desktop shortcut and start using NBoard.

### Q: Where are my drawings saved?
**A:** `C:\Users\[YourUsername]\Documents\NBoard\`
All drawings auto-save every 30 seconds.

### Q: Can I run from USB/External Drive?
**A:** YES! Portable version can run from anywhere.

### Q: How do I uninstall?
**A:** Settings → Apps → Programs and Features → Find "NBoard" → Uninstall

### Q: What if it won't start?
**A:** Make sure .NET 6.0 is installed: https://dotnet.microsoft.com/download/dotnet/6.0

## 🔧 Troubleshooting

### Problem: "NBoard.exe not found"
**Solution:** Download the installer or portable version

### Problem: ".NET 6.0 required" error
**Solution:** Install .NET 6.0 Desktop Runtime from:
https://dotnet.microsoft.com/download/dotnet/6.0

### Problem: Desktop shortcut missing
**Solution:** 
1. Locate NBoard.exe installation folder
2. Right-click NBoard.exe
3. "Send to" → "Desktop (create shortcut)"

### Problem: Can't save documents
**Solution:** Run NBoard as Administrator
1. Right-click NBoard shortcut
2. "Run as administrator"
3. Click "Yes"

### Problem: Application crashes
**Solution:**
1. Uninstall NBoard
2. Install latest .NET 6.0 Runtime
3. Restart PC
4. Reinstall NBoard
