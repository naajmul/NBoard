# 🎉 NBoard v1.0.0 - Installation & Quick Start

## ⚡ FASTEST WAY TO GET STARTED (3 Steps)

### Step 1: Install .NET 6.0 Runtime (One time only - 2 minutes)

**Download:** https://dotnet.microsoft.com/download/dotnet/6.0

1. Click **"Desktop Runtime"** (NOT SDK)
2. Download the installer
3. Double-click and install
4. **Restart your PC**

✅ **Done!** (You only need to do this once)

---

### Step 2: Download NBoard Installer

**Go to:** https://github.com/naajmul/NBoard/releases

**Download:** `NBoard-Setup.msi`

---

### Step 3: Install NBoard (1 minute)

```
1. Double-click NBoard-Setup.msi
   ↓
2. Installer wizard opens
   ↓
3. Click "Next" → "Next" → "Finish"
   ↓
4. ✅ Installation Complete!
   ↓
5. Desktop shortcut appears
   ↓
6. Double-click "NBoard" on desktop
   ↓
7. 🎨 START DRAWING!
```

## ❓ Frequently Asked Questions

### Q: Do I need Visual Studio?
**A:** NO! Just install .NET 6.0 and NBoard. That's it.

### Q: Do I need internet after installation?
**A:** NO! NBoard works completely offline.

### Q: Can I move the shortcut?
**A:** YES! Copy the desktop shortcut anywhere you want.

### Q: How do I uninstall?
**A:** 
1. Settings → Apps → Programs and Features
2. Find "NBoard"
3. Click "Uninstall"

### Q: Will my drawings be deleted?
**A:** NO! Your drawings stay in Documents/NBoard/ folder.

### Q: Can I backup my drawings?
**A:** YES! Copy the entire `C:\Users\[You]\Documents\NBoard\` folder.

### Q: How do I update to new version?
**A:** Download new NBoard-Setup.msi and install. Your drawings stay safe.

## 🆘 Troubleshooting

### NBoard won't launch?

**Solution:**
1. Install .NET 6.0 Desktop Runtime
2. Link: https://dotnet.microsoft.com/download/dotnet/6.0
3. Restart PC
4. Try again

### Desktop shortcut missing?

**Solution:**
1. Find: `C:\Program Files\NBoard\NBoard.exe`
2. Right-click → "Send to" → "Desktop (create shortcut)"
3. Rename to "NBoard"

### Can't save drawings?

**Solution:**
1. Right-click NBoard shortcut
2. "Run as administrator"
3. Click "Yes"
4. Try saving again
