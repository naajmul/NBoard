# Getting Started with NBoard

Welcome to NBoard! This is your complete guide to get up and running in minutes.

## 📥 Installation

### Prerequisites
Before you start, you need **ONE** thing:
- **.NET 6.0 Desktop Runtime** - [Download Here](https://dotnet.microsoft.com/download/dotnet/6.0)
  - Choose "Desktop Runtime" (NOT SDK)
  - Install and restart your PC

### Download NBoard
1. Go to: https://github.com/naajmul/NBoard/releases
2. Download: **NBoard-Setup.msi**
3. Double-click the file
4. Follow the installer wizard
5. Click "Finish" when done

### Desktop Shortcut
After installation:
- **Desktop shortcut named "NBoard"** appears automatically
- Double-click to launch
- OR search for "NBoard" in Windows Start Menu

---

## 🎨 Your First Drawing

### Launch NBoard
1. Double-click "NBoard" icon on desktop
2. Welcome screen opens
3. Click "+ Create New Document"
4. **Blank canvas appears!** Ready to draw.

### Basic Drawing
```
1. Select tool from toolbar (✏️ Pen is default)
2. Click on canvas and drag to draw
3. Your drawing auto-saves every 30 seconds
4. Done! 🎨
```

### Change Color
1. Click the **Color Button** (black square in toolbar)
2. Choose your color
3. Click OK
4. Draw with new color

### Adjust Size
1. Move the **Size Slider** (1-50)
2. Number updates in real-time
3. Draw with new size

## 💾 Saving & Opening

### Auto-Save (Automatic)
✅ Your work is automatically saved every 30 seconds
✅ Saved to: `C:\Users\[YourName]\Documents\NBoard\`
✅ You don't need to do anything!

### Manual Save
- **File → Save** (Ctrl+S)
- Saves immediately

### Open Existing Document
1. Launch NBoard
2. Welcome screen shows recent files
3. Click "Open" next to document name
4. OR click "📁 Open File" to browse

---

## 📤 Export Your Drawing

**File → Export:**

1. **PDF** - For printing and sharing
   - Opens in PDF reader
   - Professional quality

2. **PNG** - Image file
   - Use on websites
   - Share on social media

3. **SVG** - Vector graphic
   - Edit in graphics software
   - Scalable without quality loss

4. **JSON** - Project file
   - Contains all layers
   - Can re-import into NBoard

## 📂 Document Management

### Recent Documents (Welcome Screen)
- Shows your 10 most recent files
- Click "Open" to continue working
- Click "Delete" to remove (with confirmation)

### All Documents Location
```
C:\Users\[YourName]\Documents\NBoard\
```
You can:
- ✅ Backup files (copy folder)
- ✅ Delete files (delete .wbd files)
- ✅ Move files (to other computers)
- ✅ Restore files (from backup)

## 🎯 Tips & Tricks

### Drawing Tips
- Use **Slider** to adjust pen size (1-50 pixels)
- Click **Color Button** to pick any color
- Press **Ctrl+Z** to undo mistakes immediately
- Press **Ctrl+Y** to redo

### Organization
- Name documents clearly: "Project_Name_Date"

## ❓ Common Tasks

### Create Desktop Shortcut (if missing)
1. Find: `C:\Program Files\NBoard\NBoard.exe`
2. Right-click → "Send to" → "Desktop (create shortcut)"
3. Rename to "NBoard"
4. Done!

### Run NBoard as Administrator
1. Right-click NBoard shortcut
2. Select "Run as administrator"
3. Click "Yes"

### Create Backup
1. Open: `C:\Users\[YourName]\Documents\NBoard\`
2. Copy entire folder
3. Save to external drive or cloud

### Restore from Backup
1. Copy backup folder
2. Paste into: `C:\Users\[YourName]\Documents\NBoard\`
3. Overwrite when prompted

## 🆘 Need Help?

### Application won't start?
- Install .NET 6.0 Runtime: https://dotnet.microsoft.com/download/dotnet/6.0
- Restart PC
- Try again

### Can't save documents?
- Run NBoard as Administrator (right-click shortcut)
- Check disk space available
- Try another location (Desktop)

### Desktop shortcut missing?
- Right-click NBoard.exe in Program Files
- Send to → Desktop (create shortcut)
